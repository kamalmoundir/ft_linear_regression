# ft_linear_regression

An introduction to machine learning — implementing simple linear regression with gradient descent, from scratch, to predict a car's price based on its mileage.

## Overview

This project implements a linear regression model with a single feature (mileage) trained using batch gradient descent. No machine learning libraries (e.g. `numpy.polyfit`, `sklearn`) are used to compute the model — the training algorithm is implemented manually as required by the subject.

**Hypothesis:**
```
estimatePrice(mileage) = theta0 + (theta1 * mileage)
```

## Project structure

```

├── utils.py        # shared functions: read_data, estimate_price, read_thetas, get_mileage, r_squared
```

## Usage

### 1. Train the model

```bash
python train.py
```

This reads `data.csv`, normalizes the mileage values, runs gradient descent for a fixed number of iterations, de-normalizes the resulting parameters back to real mileage scale, and saves `theta0` and `theta1` to `thetas.txt`.

Example output:
```
number of inputs :  24
theta0: 8477.133173873699
theta1: -0.02123530112566652
```

### 2. Predict a price

```bash
python predict.py
```

Prompts for a mileage and prints the estimated price using the saved thetas. If `thetas.txt` does not exist yet (i.e. the model hasn't been trained), theta0 and theta1 default to 0, as required by the subject.

Example:
```
Enter a mileage: 100000
predicted price : 6353.603061307047
```

Handles common input issues gracefully: thousands-separator commas (`97,500`), non-numeric input, and negative mileage (re-prompts instead of crashing). Negative predicted prices are clamped to 0.

### 3. Bonus — precision and visualization

```bash
python bonus.py
```

Prints the R² (coefficient of determination) of the trained model, and opens a plot showing the raw data points alongside the fitted regression line.

Example output:
```
R² (precision): 0.7329
```

## The algorithm

### Training formulas

On each iteration, both parameters are updated **simultaneously** using the values computed from the *current* theta0/theta1 (not the newly updated ones):

```
tmpTheta0 = learningRate * (1/m) * Σ(estimatePrice(mileage[i]) - price[i])
tmpTheta1 = learningRate * (1/m) * Σ(estimatePrice(mileage[i]) - price[i]) * mileage[i]

theta0 = theta0 - tmpTheta0
theta1 = theta1 - tmpTheta1
```

where `m` is the number of data rows in the dataset.

### Feature scaling

Raw mileage values (tens to hundreds of thousands) are on a vastly different scale than price values (thousands), which causes gradient descent to diverge if used directly. Mileage is normalized to a 0–1 range before training:

```
normalized_mileage = (mileage - mileage_min) / (mileage_max - mileage_min)
```

After training, the resulting theta0/theta1 (fit to normalized mileage) are converted back to work directly with raw mileage input:

```
new_theta1 = theta1 / (mileage_max - mileage_min)
new_theta0 = theta0 - new_theta1 * mileage_min
```

This means `predict.py` can use `theta0 + theta1 * mileage` directly with real mileage values, exactly matching the hypothesis specified in the subject.

### Precision metric (R²)

```
R² = 1 - (SS_res / SS_tot)

SS_res = Σ(price_i - estimatePrice(mileage_i))²
SS_tot = Σ(price_i - mean(price))²
```

R² indicates the proportion of variance in price explained by mileage. A value close to 1 indicates a strong fit; a value close to 0 indicates the model is no better than always predicting the average price.

## Notes on library usage

- `numpy` is used only for array storage and elementwise arithmetic (subtraction, multiplication, summation) — the gradient descent loop itself, including the update rule and convergence, is implemented manually.
- `numpy.polyfit`, `scipy.stats.linregress`, and similar functions that compute regression coefficients directly are **not used**, per the subject's restrictions.
- `matplotlib` is used only for the bonus visualization, as suggested by the subject for debugging purposes.
